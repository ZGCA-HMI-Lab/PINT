# PINT: A Unified Model with Shared Predictive Intent for Robot Manipulation

Official repository for **PINT**.

> Code will be released soon.

## Overview

**Multiple experts, one intent.**<br>
PINT introduces a shared chunk-level **Predictive Intent** to coordinate semantic reasoning, world modeling, and action generation while preserving specialized expert pathways.

Without embodied pretraining, PINT achieves strong in-distribution performance and out-of-distribution generalization across RoboTwin 2.0, LIBERO, LIBERO-Plus, and real-world tasks.
